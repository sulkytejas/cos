Memory v2 — memory that predicts, not memory that recalls. Why, how, and what shipped.

0 · The idea one sentence

Knowing someone deeply doesn't mean storing more facts about them — it means being able to predict them. ChatGPT-style memory is a paragraph of declarations: it can recall that you have a dog; it cannot anticipate you. Atlas is a memory product, so memory must be the organ, not a feature. The qualitative jump is a loop, not a bigger archive.

Confirmed → backing notes reinforce. Refuted → they weaken. Being wrong becomes raw material. The calibration ledger (Brier score, stated-confidence vs hit-rate) rides every prompt, so Ayumi hedges exactly where it has historically been wrong.

2 · Decisions written down so we never argue them twice

DecisionWhy
Predictions are observation rows, not a new tableSame receipts discipline, same red pen, same sync. A bet is just a note about the future with a grade pending.
Numeric confidence, mandatory"Probably" can't be scored. The number is the hedge — and the only way calibration (Brier) is computable.
Small and near, not grandDaily-resolvable bets give ~365 training cycles a year; grand ones give three. Fast loops are how it gets good.
Passive forecasts onlyIf Ayumi predicts you'll skip the 7am and then doesn't prep it, it caused its own success. Never bet on what you control.
Strict judge, refuted-by-default after one grace nightTetlock's rule: an unfalsifiable forecast counts against. No grading on a curve, or calibration is fiction.
Credit assignment via basedOnIdsOutcomes must teach the BELIEFS, not just the scoreboard — that's the difference between keeping score and evolving.
Calibration in every promptKnowing what it doesn't know about you is the trust feature: the memo hedges exactly where it's historically been wrong.
